# Steps to use a Playwright agent on our system. 
1. Create one folder with the name Playwright-Agents. 
2. Open terminal Playwright-agent folder.
3. Install Playwright freshly in this folder. Using the below command 
   -> npm init playwright@latest
   -> Go with all default options and complete the installation.  

4. Open your VS Code in that dedicated project folder. 
    File -> Open Folder -> GTM_Playwright_Batch17 -> DeepeshY ->  Playwright-Agents


5. On your terminal, run the command below to create the agent in the current project. 
   -> npx playwright init-agents --loop=vscode
   -> This command will create all three agents for us on our system.
